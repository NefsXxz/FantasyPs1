Tutorial Singkat

📱 Android
  1. Download APK & PowerTunnel
  2. Install PowerTunnel
  3. Copy host (tombol di atas)
  4. Paste ke PowerTunnel > Host Settings
  5. Jalankan, buka Growtopia
💻 Windows
  1. Buka notepad sebagai admin
  2. Edit file: C:\Windows\System32\drivers\etc\hosts
  3. Tambahkan dua baris IP (copy di atas)
  4. Simpan, jalankan Growtopia
🍎 iOS
  1. Copy iOS host link
  2. Buka di Safari, install profile
  3. Buka Growtopia

Langkah-langkah

  • Download File Host
    Unduh file .txt dari tombol di samping. Simpan di penyimpanan ponsel.
  • Buka Aplikasi Virtual Host
    Install dan buka aplikasi Virtual Host yang sudah diunduh.
  • Pilih File Host
    Tekan tombol re-select file lalu cari file EldoriaPs - GTPSHOST (5).txt.
  • Aktifkan Host
    Tekan tombol START/ikon power untuk mengaktifkan virtual host.
  • Mainkan Growtopia
    Buka game Growtopia dan login. Selamat bermain di Eldoria!
